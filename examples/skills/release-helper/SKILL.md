# Release Helper

Use this skill when the user asks for release preparation, changelog drafting, version checks, or pre-release validation.

## Instructions

1. Check the current version in `package.json`.
2. Review recent changes and group them into Features, Fixes, Improvements, and Breaking Changes.
3. Confirm that lint, typecheck, tests, and build pass.
4. Draft concise release notes with user-facing changes only.
5. Call out any migration or credential implications.
