# Angel Examples

These examples show common safe starting points for Angel configuration and extension points. Copy them into your Angel config directories and replace placeholders with your own values.

## Contents

- `configs/` — complete configuration profiles
- `hooks/` — hook configuration examples
- `plugins/` — plugin manifest examples
- `skills/` — skill file examples
- `recipes/` — workflow recipe examples

Use environment variable placeholders for secrets, for example `${OPENAI_API_KEY}`. Do not commit real API keys or tokens.
